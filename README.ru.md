# SGC-NOVUS Tools (`Novus_Tools@sgc-novus.fun`)

[![GNOME Shell](https://img.shields.io/badge/GNOME%20Shell-45--50-blue.svg)](https://extensions.gnome.org/)
[![Лицензия: GPL-3.0](https://img.shields.io/badge/License-GPLv3-green.svg)](LICENSE)

[English](README.md) | Русский

**SGC-NOVUS Tools** — это комплексное расширение для GNOME Shell (45–50) для автоматизации системного окружения: переключения тем день/ночь, динамических обоев, синхронизации с «Ночным светом», плавной регулировки яркости мониторов, управления сценариями энергопотребления и телеметрии Swap/гибернации по D-Bus.

---

## Основные возможности

- **Управление энергопотреблением и умные сценарии (`org.freedesktop.UPower.PowerProfiles` и `UPower`)**
  - Мгновенное переключение между профилями **Максимальная производительность** (`performance`), **Сбалансированно** (`balanced`) и **Максимальное энергосбережение** (`power-saver`) в меню быстрых настроек GNOME (Quick Settings) через асинхронный D-Bus.
  - **Умные сценарии питания**: автоматический выбор профиля при подключении/отключении зарядного устройства и переход в энергосбережение при низком заряде батареи.
  - **Адаптивные таймауты, снижение частоты 60 Гц, подсветка клавиатуры и OLED-режим**: раздельное время отключения экрана, автоматическое снижение герцовки дисплея до 60 Гц от батареи/в энергосбережении (`org.gnome.Mutter.DisplayConfig`), управление подсветкой клавиатуры (`org.freedesktop.UPower.KbdBacklight`) и тёмная тема в энергосбережении.
  - **Режим «Не засыпать (Кофеин)»**: блокировка гашения экрана и сна через `org.gnome.SessionManager.Inhibit` с выбором времени действия.
  - **Расширенная телеметрия батареи**: отображение текущего потребления (`Вт`), здоровья аккумулятора (`%`) и числа циклов зарядки.
  - **Автоматизация по расписанию День / Ночь**: синхронизация профилей питания с дневным и ночным периодами.

- **Спящий режим, гибернация и мониторинг Swap (`org.freedesktop.login1.Manager`)**
  - Быстрые действия **Спящий режим**, **Сон с переходом в гибернацию (`Suspend-then-Hibernate`)**, **Гибридный сон** и **Гибернация** из Quick Settings и окна настроек.
  - Аварийная автоматическая гибернация при достижении критического порога разряда аккумулятора.
  - Неблокирующая асинхронная диагностика раздела/файла подкачки (`/proc/swaps`, `/proc/meminfo`, `vm.swappiness`) и проверка готовности памяти к гибернации.

- **Астрономическое расписание (`SunCalc` + `GeoClue2`)**
  - Локальный расчёт 14 солнечных фаз (`sunrise`, `sunset`, `golden_hour`, `dusk` и др.) или настройка точного времени `ЧЧ:ММ`.
  - Автоматическое определение местоположения по запросу в настройках через `GeoClue2` с резервным определением по IP (`ipinfo.io`) и города через OpenStreetMap (`nominatim.openstreetmap.org`).

- **Управление темами, иконками, акцентными цветами и обоями**
  - Переключение `org.gnome.desktop.interface` (`color-scheme`, `gtk-theme` и `icon-theme`) с автоподбором светлых и тёмных пар (`Yaru*`, `Adwaita*`, `Papirus*` и сторонние темы) и синхронизацией акцентных цветов Ubuntu/GNOME.
  - Смена обоев рабочего стола (`picture-uri` / `picture-uri-dark`), поддержка системных XML-обоев и раздельных файлов изображений, опциональное обновление экрана блокировки.

- **Асинхронное управление яркостью и Ночным светом по D-Bus**
  - **Встроенные экраны**: управление через `org.gnome.Mutter.DisplayConfig` (свойство `Backlight` и метод `SetBacklight` в GNOME 49/50) с фолбэком на `org.gnome.SettingsDaemon.Power`.
  - **Внешние DDC/CI мониторы**: управление по D-Bus через службу [`ddcutil-service`](https://github.com/digitaltrails/ddcutil-service) (`com.ddcutil.DdcutilService` VCP `0x10`) без порождения подпроцессов.
  - Плавные косинусные переходы яркости вокруг времени восхода и заката, а также настройка цветовой температуры Ночного света (`1700K–4700K`).
  - Экспорт и импорт конфигурации в JSON и полный сброс настроек.

- **Соответствие эталонам EGO Review Guidelines**
  - Никаких вызовов команд оболочки через `spawn` и никаких блокирующих чтений в главном цикле — только нативные асинхронные D-Bus интерфейсы и `Gio.File.load_contents_async()`.
  - Полная очистка всех таймеров, подписок на сигналы и `Gio.Cancellable` при выключении расширения (`disable()`).
  - Современный интерфейс настроек на Libadwaita (GTK4 / Adw) с поддержкой глобального поиска.

## Установка

### Из исходного кода

```bash
git clone https://github.com/SGC-NOVUS/novus-tools.git
cd novus-tools
make install
gnome-extensions enable Novus_Tools@sgc-novus.fun
```

### Сборка EGO-пакета (`Novus_Tools@sgc-novus.fun.zip`)

```bash
make pack
```
